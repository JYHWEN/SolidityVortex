# SolidityVortex

Transforms and compiles Solidity smart contracts into efficient bytecode for Ethereum blockchain development.

With SolidityVortex, you get a lightweight tool that stays out of your way.

**What you get**

- Transforms and compiles Solidity smart
- contracts into efficient bytecode for
- Ethereum blockchain development

## Key Features

- Transforms and compiles Solidity smart
- contracts into efficient bytecode for
- Ethereum blockchain development

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SolidityVortex.git`
2. `cd SolidityVortex`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SolidityVortex, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
